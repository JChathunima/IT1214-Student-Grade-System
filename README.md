# IT1214-Student-Grade-System

## Project Purpose
This project is a Java console-based Student Grade Management System developed using Object-Oriented Programming (OOP) concepts.

The system allows teachers to:
- Add students
- Display all student records
- Search students by ID
- Calculate average marks
- 

## Technologies Used
- Java
- GitHub

## How to Run the Program

1. Compile the Java files:
javac Main.java Student.java

2. Run the program:
java Main
